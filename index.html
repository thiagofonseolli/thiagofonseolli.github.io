Os dados deste painel são salvos direto na nuvem (não neste navegador) — qualquer computador ou celular que abrir este link já vê e edita os mesmos dados. O botão 💾 Salvar envia imediatamente qualquer alteração; sem clicar nele, o app também sincroniza sozinho a cada poucos segundos. Mesmo assim, use o botão ⬆️/⬇️ Exportar/Importar backup regularmente para guardar uma cópia de segurança em arquivo — é a sua rede de proteção contra uma exclusão em massa por engano.
